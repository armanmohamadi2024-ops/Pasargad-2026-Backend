# Pasargad 2026 — Backend v1

این مرحله «بک‌اند واقعی» است؛ هنوز درگاه بانکی و احراز هویت کامل را وصل نکرده‌ایم.

## چیزی که الان داریم
- Node.js + Express
- SQLite Database
- محصولات
- مشتری‌ها
- سفارش‌ها
- موجودی محصول
- رنگ و سایز
- API برای افزودن/ویرایش/حذف محصول
- API برای ساخت و مشاهده سفارش
- API برای تغییر وضعیت سفارش
- داده اولیه تیشرت پاسارگاد 2026

## راه‌اندازی
1. Node.js نسخه LTS را نصب کن.
2. داخل همین پوشه ترمینال باز کن.
3. اجرا کن:
   npm install
4. بعد:
   npm start
5. باید این پیام را ببینی:
   Pasargad 2026 API running at http://localhost:3000

## تست
در مرورگر:
http://localhost:3000/api/health

باید پاسخ JSON با ok=true ببینی.

لیست محصولات:
http://localhost:3000/api/products

## نکته مهم
این Backend برای شروع پروژه واقعی ساخته شده، اما قبل از انتشار عمومی باید احراز هویت مدیر، اعتبارسنجی امنیتی، مدیریت فایل/تصویر، لاگ، پشتیبان‌گیری، HTTPS، rate limiting و درگاه پرداخت واقعی را اضافه کنیم.
