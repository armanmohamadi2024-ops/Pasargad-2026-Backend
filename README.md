# Pasargad 2026 — Backend v2 (PostgreSQL)

نسخه PostgreSQL بک‌اند فروشگاه پاسارگاد 2026.

## اجرا
1. متغیر محیطی `DATABASE_URL` را تنظیم کنید.
2. `npm install`
3. `npm start`

در Render، مقدار `DATABASE_URL` باید Internal Database URL دیتابیس PostgreSQL باشد.

## تست
`/api/health` علاوه بر سلامت API، اتصال PostgreSQL را نیز بررسی می‌کند.

پاسخ موفق شامل:
- `ok: true`
- `database: "connected"`

## امکانات فعلی
- PostgreSQL
- محصولات و جستجو/دسته‌بندی
- افزودن/ویرایش/حذف محصول
- مشتریان

- کاهش موجودی هنگام ثبت سفارش
- تغییر وضعیت سفارش
- ایجاد خودکار جداول
- ایجاد خودکار محصول اولیه تیشرت پاسارگاد 2026
